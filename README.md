# 坦克大战 · Tank Battle

一个用纯 HTML + Canvas + JavaScript 实现的经典《坦克大战》网页游戏，无需任何依赖，单文件即可运行。

## 🎮 玩法

- 控制黄色坦克，消灭所有敌方坦克并守护底部的基地（鹰徽）。
- 基地被击毁或生命耗尽则游戏结束。
- 每关 20 辆敌方坦克，全部消灭后进入下一关，通关全部 3 关即获胜。

## 🕹️ 操作

| 动作 | 按键 |
|------|------|
| 移动 | 方向键 / WASD |
| 射击 | 空格 / J |
| 暂停 / 继续 | P |
| 开始 / 下一关 / 重开 | Enter |

## 🧱 地形

- **砖墙**：可被子弹摧毁，也是敌人的攻击目标。
- **钢墙**：不可摧毁（拿到 ⭐ 星形道具后可击穿一段时间）。
- **水**：坦克无法通过，子弹可以穿过。
- **树**：遮挡视线，坦克和子弹都能穿过。

## ⭐ 道具

| 道具 | 效果 |
|------|------|
| ★ 星形 | 10 秒内子弹可击穿钢墙、射速提升 |
| ◈ 护盾 | 8 秒内免疫敌方子弹 |
| ♥ 生命 | 增加一条生命（上限 9） |

## 🚀 运行

直接用浏览器打开 `index.html` 即可，无需构建或安装依赖。

也可以使用任意静态服务器（例如）：

```bash
npx serve .
# 或
python -m http.server 8000
```

然后访问 http://localhost:8000

## 🛠️ 技术说明

- 纯原生 Canvas 2D 渲染，无第三方库。
- 地图为 13×13 网格，支持多关卡（`LEVELS` 数组）。
- 碰撞检测：AABB + 网格，移动采用分轴处理。
- 音效通过 Web Audio API 实时合成，无音频文件。
